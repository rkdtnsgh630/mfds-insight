## 7. 권장 등급 실측 후 재평가 (2026-11-17)

| API | 실측 | 평가 변화 |
|---|---|---|
| DUR 품목정보 | ITEM_SEQ 전 오퍼레이션 보유, 병용금기 79만 건 | 권장 유지. 품목 상세에 바로 연결 가능. 병용금기는 수집량이 커서 단계적 수집 |

| 재심사 / 재평가 | BIZRNO만, 품목 키 없음 | 권장 유지, 품목 연계는 검증대기 |
