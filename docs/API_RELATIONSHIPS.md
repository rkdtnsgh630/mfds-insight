# API 간 연계 가능성

갱신: 2026-11-17. 근거는 **10개 API 실제 응답 필드** (API_CATALOG.md E절). 각 API 첫 100건에서 형식을 점검했으며, 실제 레코드끼리 값이 일치하는지(조인 성공률)는 전체 수집 후 측정한다. 업체명·주소가 비슷하다는 이유만으로 동일 업체·제조소로 확정하지 않는다.

## 1. 핵심 결론

**`BIZRNO`(사업자등록번호, 10자리)가 10개 API 전부에 존재**한다. 업체 단위 연계의 1순위 키로 사용한다.
- GMP 적합판정·해외제조소처럼 다른 업체 ID가 없던 API도 업체 단위로는 연결 가능해졌다.
- 단, **제조소(공장) 단위 연계는 여전히 불확실**하다. 한 업체가 여러 공장을 가지므로 GMP의 `FCTR_ADDR`와 업체허가 상세의 `FCTRY_ADDR1/2`는 주소 문자열 비교에 의존한다 → `검증대기`로 관리.

품목 단위 1순위 키는 `ITEM_SEQ`(품목기준코드)다.

## 3. 연계 구조

```
                         BIZRNO (업체)
   ┌──────────┬──────────┬──────┴───┬───────────┬──────────┐
 업체허가   제품허가    행정처분    GMP판정    해외제조소   공급중단 …
 (PRMISN_NO) (ITEM_SEQ)  (ITEM_SEQ)  (공장주소)  (MFTR_PRMSN_NO)
                │
       ITEM_SEQ (품목)
   ┌──────┬─────┴────┬──────────┬──────────┐
 주성분  생산·수입실적  회수·판매중지  공급중단   행정처분
                         (STD_CD)   (EDI_CODE)
```

## 4. 연계 시나리오 (홈페이지 기능 기준)

| 기능 | 연결 방식 | 신뢰도 |
|---|---|---|
| 업체 상세: 허가품목 수, 처분·회수·공급중단 이력, GMP 판정, 생산실적 합계 | BIZRNO | 높음 (조인 성공률 측정 필요) |
| 품목 상세: 성분, 연도별 생산·수입액, 회수·공급중단·처분 이력 | ITEM_SEQ | 높음 |
| 표준코드 기반 공급중단 ↔ 제품허가 | EDI_CODE (STD_CD와 동일 체계인지 미확인) | 중간 |
| 수입업체 ↔ 해외제조소 국가 분포 | BIZRNO | 높음 (업체 단위) |
| GMP 판정 ↔ 국내 공장 | BIZRNO + 공장주소 문자열 | **낮음** → 검증대기 |

## 5. 주의사항

- 행정처분은 `ENTP_SEQ`가 실제로 없으므로 업체 연계는 BIZRNO 또는 ENTP_NO를 사용한다.
- 의약외품은 BIZRNO 누락이 일부 있어(500건 중 3건) ENTP_SEQ를 보조 키로 둔다.
- 사업자번호가 바뀐 업체(합병·분할)는 동일 업체 판정이 어렵다 → 이력 테이블 필요.
- 같은 의미의 필드명이 API마다 다르다 (ENTP_NAME/ENTRPS/BSSH_NM 등). 표준화 계층에서 통일한다.

## 6. 권장 14개 실측 결과 반영 (2026-11-17)

| API | BIZRNO | ITEM_SEQ | 기타 키 | 연계 방식 |
|---|---|---|---|---|
| DUR 품목정보 (9개 오퍼레이션) | 일부 오퍼레이션만 | ✔ 전부 | INGR_CODE(성분), MIXTURE_ITEM_SEQ(병용 상대) | **ITEM_SEQ** |
| 공급부족 | ✔ | ✔ | ENTP_SEQ, EDI_CODE | ITEM_SEQ + BIZRNO |
| 재심사 / 재평가 | ✔ | ✘ (`ITEM_NO`는 다른 체계) | ENTP_NO(재평가) | BIZRNO, 품목은 **문자열 추정 → 검증대기** |
| 생동성인정품목 | ✔ | ✔ | | ITEM_SEQ + BIZRNO |
| DMF | ✔ | ✘ | DMF_PERMIT_NO, 제조원·국가 | BIZRNO (업체 단위) |
| 의약품 특허정보 | ✘ | ✔ | DOMESTIC_PATENT_NO | ITEM_SEQ |
| 국내 특허현황 | ✘ | 후보 (`PTNT_PRDLST_CRTR_CD` 9자리) | PTNT_NO | 값 일치 검증 후 결정 |
| 묶음의약품 | ✘ | 후보 (`cnsgnItemSeq` 9자리) | trustHiraPrductCode, trustAtcCode | 값 일치 검증 후 결정 |
| 임상시험 정보 / 계획 상세 | ✘ | ✘ | CLNC_TEST_SN (두 API 공통 필드명) | 업체는 의뢰자명 문자열만 → 검증대기 |
| 안전성서한 | ✘ | ✘ | SAFT_LETT_NO | 품목·업체 연계 불가 (문서 단위 콘텐츠) |
| 우선판매품목허가 | ✘ | ✘ | 없음 | 성분·품목명 문자열 → 검증대기 |

결론:
- `ITEM_SEQ`가 가장 넓게 퍼진 키다 (제품허가·DUR·공급중단·공급부족·회수·행정처분·생산실적·생동성·특허정보 등).
- `BIZRNO`는 업체 마스터·규제 계열에는 있으나 특허·임상·서한 계열에는 없다.
- 특허·임상 메뉴는 업체 연결이 문자열에 의존하므로, 화면에 "연계 추정" 표시가 필요하다.

## 7. 미승인 API의 연계 후보 (공식 명세 기준, 실측 아님)

| 식별자 | API | 연결 대상 | 확인 필요 |
|---|---|---|---|
| `ITEM_SEQ` | 생동성인정품목 (15058447) | 제품허가 | 값 일치 여부 |
| `itemSeq` (camelCase) | e약은요 (15075057) | 제품허가 | 값 일치 여부 |
| `PRDLST_SN` (품목일련번호) | 마스크 3종, 감염병치료제 | 제품허가·의약외품 ITEM_SEQ | **같은 체계인지 미확인** |
| `CPNT_CD` (성분코드) | 1일최대투여량 (15098095), 희귀의약품성분 (15073980) | 제품허가 주성분 `MTRAL_CODE` | **같은 체계인지 미확인** |
| 업체명·성분명 문자열 | 우선판매품목, 통지의약품, DMF, 특허 계열 등 | 업체·품목 | 문자열 추정만 가능 → 검증대기 |
| `BIZRNO` | (명세에 없음) | 업체 | 승인 API 10개에서는 명세에 없어도 실제로 반환됨 → 승인 후 실측 |

## 8. 연계 상태 관리

| 상태 | 의미 |
|---|---|
| 공식식별자일치 | BIZRNO, ITEM_SEQ 등 공식 식별자 값이 일치 |
| 문자열추정 | 업체명·주소 등 문자열만 일치 |
| 검증대기 | 연계 후보이나 확인되지 않음 |
| 연계불가 | 식별자 없음 또는 충돌 |
