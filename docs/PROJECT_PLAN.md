# 프로젝트 계획 (사용자 확정 요구사항 요약)

출처: 사용자 지시 2건 (2026-11-17). 아래 요구사항은 사용자가 확정한 내용이며 임의로 바꾸지 않는다.

## 목표

식품의약품안전처(MFDS) 공공데이터 API를 통합하여 국내 제약산업, 의약품, 제조업체, GMP, 행정처분, 안전정보, 최신 변경사항을 검색·분석하는 공개 웹 플랫폼. 단순 API 조회가 아니라 공공데이터를 연계한 통계, 비교, 변경이력, 맞춤 분석을 제공한다.

## 운영 방향

- 누구나 접속 가능한 공개 홈페이지, 회원가입 없이 기본 검색·분석
- 회원: 관심 업체·품목, 맞춤 대시보드, 변경 알림
- PC 우선 설계, 모바일 반응형, 한국어 UI
- 무료 오픈소스·무료 서비스 우선. 유료 API·호스팅·데이터 서비스 금지, 승인 없는 유료 신청 금지

## 핵심 기능 (8개 메뉴)

종합 대시보드 / 제약회사 분석 / 의약품·품목 분석 / 제약산업 통계 / GMP·규제 분석 / 의약품 안전정보 / 최신 변경사항 모니터링 / 회원별 맞춤 기능

## 데이터 운영

하이브리드: 정기 수집·저장 + 검색은 저장 데이터 우선 + 필요 시 원본 재호출. 수집 주기는 API별 실제 갱신주기를 조사해 설정. 변경이력 축적. 과거 데이터가 없으면 임의 생성 금지.

## 단계

- Phase 1: API 조사 및 데이터 구조 분석 (현재)
- Phase 2: 수집 기반 구축
- Phase 3: 홈페이지 MVP
- Phase 4: 고급 분석
- Phase 5: 공개 운영 및 개인화

각 단계는 완료 기준을 충족한 뒤 다음으로 진행한다.
