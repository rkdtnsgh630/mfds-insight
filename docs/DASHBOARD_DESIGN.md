# 대시보드 및 분석 기능 설계 (초안)

원칙: 화면별 API 1:1 구성이 아니라 여러 API를 연결해 의미 있는 분석을 제공한다. 통계 차트에는 실제 데이터만 사용하며, 샘플 데이터를 쓸 경우 반드시 "샘플"이라고 표시한다. 데이터 기준일과 출처를 각 화면에 표시한다.

| 메뉴 | 주요 구성 | 사용 API (확인된 것) | 비고 |
|---|---|---|---|
| 종합 대시보드 | KPI 카드, 통합검색, 최근 허가·규제 동향, 산업통계 차트 | 제품허가, 행정처분, 회수·판매중지, 생산·수입실적 | KPI 정의는 실측 데이터 확인 후 확정 |
| 제약회사 통합정보 | 업체 기본정보, 허가품목 수, 생산·수입실적, GMP 판정, 행정처분·안전정보, 업체 간 비교 | 업체허가, 제품허가, 생산·수입실적, GMP, 행정처분, 공급중단 | 업체 연결은 식별자 우선, 문자열 추정은 표시 |
| 의약품·품목 분석 | 품목명·업체·성분 검색, 허가 상세, 허가·취하 현황, 관련 안전정보 | 제품허가, 회수·판매중지, 공급중단 | 주성분 상세 오퍼레이션 활용 |
| 제약산업 통계 | 연도별 생산·수입 추이, 업체별 비교, 신규 허가 추이 | 생산·수입실적 (연간), 제품허가 | 연간 갱신 주기를 화면에 명시 |
| GMP·규제 분석 | GMP 판정 현황, 제조소 정보, 행정처분 현황 | GMP 적합판정, 해외제조소, 행정처분 | GMP에 제조소 ID 없음 → 연계 상태 표시 |
| 의약품 안전정보 | 회수·판매중지, 공급중단, 관련 업체·품목 연결 | 회수·판매중지, 공급중단 | 공급중단 재고 기준일 표시 |
| 최신 변경사항 모니터링 | 신규 허가, 허가상태 변경, 신규 처분, 신규 회수, GMP 변경, 변경 전후 비교 | 수집 이력 기반 (추후) | 자체 변경이력 축적 방식은 Phase 2에서 설계 |
| 회원별 맞춤 대시보드 | 관심 업체·품목, 맞춤 KPI, 변경 알림 | 위 API 전체 | Phase 5 |

## 신규 메뉴 제안 (59개 API 조사 결과, 2026-11-17)

아래 메뉴는 아직 승인되지 않은 API(권장·선택 등급)를 사용하므로, 활용신청과 실측 후 확정한다. 상세 근거는 API_EVALUATION.md 6절.

| 제안 메뉴 | 주요 화면 | 사용 API |
|---|---|---|
| 특허·독점 모니터링 | 성분·품목별 특허 만료 타임라인, 우선판매품목 독점기간, 특허 심판 현황, 업체별 특허 수 | 의약품 특허정보, 국내 특허현황, 우선판매품목허가, 국내소송(심판), 오렌지북, Paragraph IV, 통지의약품 |
| 공급 안정성 | 공급중단·공급부족 통합 목록, 필수의약품 중 공급 위험 품목, 동일 성분 대체 품목 수 | 공급중단(승인), 공급부족, 필수의약품, 희귀필수의약품, 생산·수입실적(승인), 제품허가(승인) |
| 임상·파이프라인 | 업체별 임상시험 승인 추이, 단계·적응증 분포 | 임상시험 정보, 임상시험 계획 상세(+선정·제외기준·시험책임자), 바이오 해외임상 |
| 제네릭 분석 | 동일 성분 경쟁 품목 수, 생동성 인정 추이, 대조약 | 생동성인정품목, 대조약, 묶음의약품, 제품허가(승인) |

기존 메뉴 보강:
- 의약품·품목 분석: DUR 금기 정보(품목 단위), e약은요 소비자용 설명, 재심사·재평가 이력
- 의약품 안전정보: 안전성서한 추가
- GMP·규제 분석: 재심사·재평가, DMF 등록 현황 추가

## 추가 제안 (검증 후 채택 여부 결정)

- **업체 리스크 프로필**: 행정처분 건수 + 공급중단 건수 + 회수 건수를 업체 단위로 묶은 종합 지표 (식별자 연결 확인 후 가능)
- **품목 공급 안정성 지수**: 공급중단 재고량과 대체 품목 수 조합 (표준코드 검증 후)

위 제안은 아직 **설계 제안이며 확인된 사실이 아니다**.
